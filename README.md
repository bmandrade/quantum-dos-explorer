# Quantum DOS Explorer

Interactive and scriptable exploration of the density of states of a
rectangular quantum box (free-electron model with Gaussian-broadened
discrete energy levels).

> **Note:** this is a packaging-stage placeholder. Full documentation
> (scientific background, installation, quick start, parameters,
> limitations, etc.) is added in a later step of this project's
> development and will replace this file.

## Development install

```bash
pip install -e ".[dev]"
pytest
```
